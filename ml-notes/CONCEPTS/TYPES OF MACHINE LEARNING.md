**SUPERVISED MACHINE LEARNING**
predicting the results by learning on a set of finite input and output

type of data: numerical data and categorical data (gender, nation)

Regression: if the output of the ml model is numerical then the model is a regression model (predict price  )
Classification: if the out of the ml model is categorical then the model is classification model (predict health)

**UNSUPERVISED MACHINE LEARNING**
no output data is present so prediction isnt done, what the model does is:

Clustering: using the dataset we can categorize the data, in a huge dataset this comes handy 
Dimensionality Reduction: reduction of extra colomns that are unnecessary for data prediction by smartly handling the number of available input sets
Anamoly Detection: detecting outliers and removing them
Association Rule : building association between objects by identifying corelation from a huge set of data (walmart case study of beer and diapers) 


**SEMI-SUPERVISED MACHINE LEARNING** 
learns from unlabeled data and finds hidden patterns

**REINFORCEMENT LEARNING**
the agent learns by existing in a self learning environment and constantly learns by trial and error
